ОТЧЁТ ПО ПРОЕКТУ: Personal Assistant Telegram Bot

Назначение агента

Personal Assistant — это Telegram-бот персональный помощник, предназначенный для:
- Управления личными задачами через Telegram
- Получения актуальной информации (погода, веб-поиск)
- Управления календарём Google Calendar
- Семантического поиска по базе знаний
- Ведения контекстных диалогов с памятью

Подключённые MCP-инструменты

1. WebSearchTool
- API: ZenSerp
- Функция: Поиск актуальной информации в интернете
- Команда: search:<запрос>
- Пример: search:python programming

2. WeatherTool  
- API: OpenWeatherMap
- Функция: Получение данных о погоде
- Команда: weather:<город>
- Пример: weather:Москва

3. GoogleCalendarTool
- API: Google Calendar API (Service Account)
- Функция: Управление событиями календаря
- Команды: 
  - calendar:add:<дата>|<длительность>|<название>
  - calendar:list:<дней>
  - calendar:test

Реализация памяти и базы знаний

Память диалогов (SQLite)
- Технология: SQLite база данных
- Файл: ./data/memory.db
- Функции:
  - Хранение истории сообщений пользователей
  - Контекстная изоляция по user_id
  - Получение последних сообщений для контекста
- Структура: Таблица messages (id, user_id, role, text, ts)

Векторная база знаний (ChromaDB)
- Технология: ChromaDB с векторными эмбеддингами
- Директория: ./chroma_db
- Функции:
  - Семантический поиск по документам
  - Хранение векторных представлений текста
  - Автоматическое создание эмбеддингов
- Коллекция: assistant_docs

Интеграция памяти и поиска
- Контекстный поиск: Каждый запрос пользователя ищется в векторной базе
- История диалога: Последние 6 сообщений добавляются в контекст
- Релевантные документы: Найденные документы включаются в промпт для LLM
- Изоляция пользователей: Каждый пользователь имеет отдельную сессию и историю

Архитектура системы

Telegram Bot (main.py)
    ↓
AgentCore (agent_core.py)
    ├── Memory (SQLite) - история диалогов
    ├── VStore (ChromaDB) - векторный поиск
    ├── WebSearchTool - веб-поиск
    ├── WeatherTool - погода
    └── GoogleCalendarTool - календарь

Особенности реализации

- Асинхронная архитектура: Все операции выполняются асинхронно
- Обработка ошибок: Graceful fallback при недоступности сервисов
- Health monitoring: Встроенная проверка состояния всех компонентов
- Docker поддержка: Готовая контейнеризация с docker-compose
- Systemd интеграция: Автозапуск через systemd service
- Конфигурация: Управление через переменные окружения (.env)
